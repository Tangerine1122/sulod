# Sulod icon

`icon.svg` is the source: a gold peso coin dropping into a chili-red pocket on mango
("sulod" means "inside"). The ₱ is set in Bricolage Grotesque 800, so open it with that
font installed or it falls back to a system font.

Exported files:

| File | Size | Use |
| --- | --- | --- |
| `src/app/favicon.ico` | 16, 32 | Browser tab |
| `src/app/icon.png` | 192 | `<link rel="icon">` |
| `src/app/apple-icon.png` | 180, full bleed | iPhone home screen (iOS rounds the corners) |
| `public/icons/icon-192.png`, `icon-512.png` | rounded | Web app manifest |
| `public/icons/maskable-512.png` | full bleed, art inside the safe zone | Android adaptive icons |
